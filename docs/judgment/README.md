# 選球眼トラック — 技術を選ぶ力を鍛える

「Rust が書ける」と「Rust を**使うべきかどうか判断できる**」は別の能力です。
立派なエンジニアに必要なのは後者です。このディレクトリでは、技術を選ぶときの判断の軸を学びます。

## 判断の基本姿勢

1. **「何が一番良いか」ではなく「この状況で何を優先するか」**で考える。技術の選択は全てトレードオフです。
2. **選ばなかった案と、選ばなかった理由も説明できる**ようにする。それができて初めて「選んだ」と言えます。
3. **コストは書く時だけでなく、読む時・運用する時・人を採用する時にも発生する**。
